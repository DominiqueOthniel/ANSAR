Demande d’offre — architecture hybride

Stockage des données chez CAMTEL · Hébergement applicatif ailleurs

1. Objet

LCCA SARL souhaite une architecture hybride : le stockage des données (base PostgreSQL et fichiers) chez CAMTEL, et l’hébergement de l’application (site web + API) sur une infrastructure externe déjà en place. Nous ne sollicitons pas un VPS applicatif complet auprès de CAMTEL.

2. Répartition souhaitée

Chez CAMTEL (stockage) Base de données PostgreSQL 16
Fichiers / pièces jointes légères (exports, photos)
Sauvegardes des données si disponible
Ailleurs (hébergement app) Frontend web (SPA React)
API métier (Node.js / NestJS)
Accès utilisateurs via HTTPS

3. Volume de stockage (référence)

Empreinte actuelle Schéma / données métier : ≈ 8–50 Mo au démarrage
Croissance progressive (multi-entreprises)
Besoin demandé Espace de stockage utile de l’ordre de 50 à 100 Go (marge croissance + sauvegardes), accessible en réseau depuis l’hébergeur applicatif externe (IP autorisées / VPN / TLS).
Accès technique Connexion distante sécurisée à PostgreSQL (port dédié, SSL)
et/ou volume / partage de fichiers si proposé par CAMTEL

4. Offre attendue de CAMTEL

  • Proposition d’une offre orientée stockage / données (pas d’hébergement web complet requis)
  • PostgreSQL managé ou VPS minimal dédié base + disque, selon catalogue (réf. hosting.camtel.cm)
  • Option sauvegarde / snapshot des données
  • IP, accès réseau et consignes de sécurisation (firewall, VPN)
  • Tarif mensuel / annuel et délais de mise en service

Source catalogue consultée : https://hosting.camtel.cm/#services (VPS, stockage additionnel, Data Backups). Le dimensionnement commercial exact reste à la proposition de CAMTEL.
