Fiche technique et estimation de consommation

Demande d’offre VPS — hébergement d’applications métier multi-entreprises

1. Objet

La présente fiche décrit le projet logiciel de LCCA SARL et les besoins d’infrastructure estimés, afin de permettre à CAMTEL de proposer une offre VPS adéquate pour l’hébergement et la bascule depuis une infrastructure externe.

2. Présentation du projet

Client / PorteurLCCA SARL (LIDAF CONSULTING COORPORATION OF AFRICA)
Nature du projetApplications web métier de gestion (flotte, opérations, caisse, facturation, tiers, etc.)
PérimètrePlusieurs entreprises / instances sur le même serveur (données séparées)
UsageOutil de travail quotidien (bureau / terrain), accès navigateur web
Disponibilité souhaitée7 j / 7, priorité heures ouvrées + accès ponctuel hors horaires
Localisation utilisateursCameroun (principalement Douala et axes opérationnels)

3. Architecture technique

Type d’applicationApplication web (SPA) + API REST
FrontendReact / TypeScript (Vite), fichiers statiques servis par Nginx ou équivalent
Backend / APINode.js 20+ (NestJS / Express), port HTTP 3000 (ou reverse-proxy 80/443)
Base de donnéesPostgreSQL 16
Système d’exploitation souhaitéLinux Ubuntu LTS (22.04 ou 24.04)
AccèsHTTPS (certificat TLS), SSH administrateur, IP publique fixe
Composants sur le VPSNginx + API Node + PostgreSQL (+ éventuellement plusieurs instances applicatives)

4. Modules métier principaux

  • Gestion flotte (camions), chauffeurs, trajets / missions
  • Caisse, banque, crédits, dépenses
  • Facturation, clients / tiers, fournisseurs et chargements
  • Opérations (TJK, Camrail, dépôt, articles, audit)
  • Exports PDF / Excel et pièces jointes légères (photos véhicules)

Le dimensionnement précis du VPS (CPU, RAM, stockage, débit) est laissé à l’appréciation de CAMTEL, sur la base des informations ci-dessus.

6. Services attendus de CAMTEL

  • Proposition d’une offre VPS adaptée à la charge décrite
  • Mise à disposition d’un VPS Linux (Ubuntu LTS) avec accès root / SSH
  • IP publique et connectivité Internet stable
  • Possibilité d’ouvrir les ports HTTP/HTTPS (80/443) et SSH (22)
  • Option sauvegarde / snapshot si disponible
  • Accompagnement pour la mise en service et communication du SLA / délais

7. Points hors périmètre immédiat

  • Pas de besoin de messagerie (mail serveur) sur ce VPS au démarrage
  • Pas de besoin de GPU / calcul haute performance
  • Pas de trafic multimédia lourd (vidéo)
